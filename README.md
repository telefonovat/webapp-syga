# SYGA(See Your Graph Algorithm)

The frontend code for SYGA.

## How to  run

### Locally

Firstly, install dependencies through `pnpm install`

Run `pnpm run dev` to expose the webapp through `http://localhost:8080`. Note that this is only the frontend and essentially useless without setting up the backend API and engine.


### Docker image

A production image of the webapp can be downloaded from [Dockerhub](https://hub.docker.com/repository/docker/kheltan/syga-prod-webapp).
